## Goal and exact behavior (decided with the user)
Languages that matter: English and ANY Indian language, in any mix. The user sometimes sees transcripts come out in the wrong script/language (Hindi written in Urdu script, or Chinese output for Hindi/English audio). Requirements:
A. TRANSCRIPT in English letters: whatever Indian language is spoken, the displayed/forwarded transcript text is in Roman/Latin letters, the way people type it in chat, e.g. "Mujhe aap batao ki angular vs react me kya difference hai". English speech stays normal English. Transliterate, NEVER translate; keep English words, code/technical terms, numbers and punctuation unchanged.
B. ANSWERS in the language of the question but written ONLY in English letters: Hindi/Urdu/Hinglish question -> Roman Hinglish answer (existing 'hing' style); Marathi question -> Marathi written in Roman letters; likewise Tamil, Telugu, Bengali, Gujarati, Punjabi, Kannada, Malayalam, etc.; English question -> English. Code blocks and technical terms stay as normal code/English.
C. Wrong-language protection: an utterance whose text is in a script that is not plausible for the user's selected languages (typically Chinese/Japanese/Korean/Arabic hallucinations when the user selected English + Indian languages) must be retried once and otherwise dropped, not shown or answered.
D. It is a user option "Show everything in English letters", DEFAULT ON, persisted in localStorage, with the old behavior fully intact when OFF or when the `roman` field is absent (backward compatible: the Audio tab and old clients keep working unchanged).
